# Notes for Claude Code

This is Ehsan's personal portfolio: a static GitHub Pages site with no framework and no deploy-time build.

- Content lives only in `data/*.json`. To add or change a project, job, skill or degree, edit the JSON and don't touch `index.html`. The schema is in `docs/data-schema.md`.
- `index.html` holds the section layout and the `<template>` blocks. Renderers in `js/render/` clone those templates and fill them with `textContent`. Never build markup from data with `innerHTML`, and pass URLs through `safeUrl()`.
- Styles: edit `scss/` only, then run `npm run sass:build` and commit the compiled `css/styles.css` (Pages doesn't run npm). Colours and spacing come from CSS variables in `scss/_tokens.scss`, and both light and dark themes must keep WCAG AA contrast.
- Icons: SVG sprite `images/icons.svg`, generated by `npm run icons` from the list in `scripts/build-icons.mjs`.
- Before finishing any change, run `npm run validate`. For visual changes, check 360px and 1280px widths in both themes, with no horizontal scroll at 360px.
- `todo` fields in the data are private reminders for Ehsan. Don't render them, and don't invent content to resolve them.
- Keep the static SEO copy in `index.html` (`<title>`, meta description, Open Graph, JSON-LD) in sync with `data/site.json` when the name or headline changes.
- Don't publish unpublished research details (the Concordia EVD/ultrasound work) beyond what `data/` already says, unless Ehsan provides the text.
